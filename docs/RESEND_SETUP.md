# Инструкция по настройке Resend для отправки писем

Для того чтобы система могла отправлять проверочные OTP коды на **любые** email-адреса, необходимо подтвердить владение доменом `cvpilot.uz` в сервисе Resend.

Это делается один раз.

---

### Шаг 1: Регистрация и получение ключа
1. Перейди на сайт [resend.com](https://resend.com) и зарегистрируйся (можно через Google/GitHub).
2. В боковом меню выбери **API Keys** → нажми **"Create API Key"**.
3. Дай ключу любое имя (например, `CV Pilot Backend`), выбери `Full Access`.
4. Тебе покажут длинный ключ, начинающийся с `re_...`. **Скопируй и сохрани его** (он показывается только один раз).
5. Зайди на сервер и вставь этот ключ в файл `.env.prod` в поле `SMTP_PASSWORD`:
   ```env
   SMTP_HOST=smtp.resend.com
   SMTP_PORT=465
   SMTP_USER=resend
   SMTP_PASSWORD=re_ТУТ_ТВОЙ_СЕКРЕТНЫЙ_КЛЮЧ
   ```

---

### Шаг 2: Добавление домена в Resend
*По умолчанию Resend находится в песочнице и дает отправлять письма только на твой личный Email регистрации. Чтобы отправлять пользователям на gmaill.com, yandex.ru и другие почты, нужно добавить домен.*

1. В боковом меню Resend выбери **Domains** → нажми **"Add Domain"**.
2. В поле Domain name впиши: `cvpilot.uz`.
3. В поле Region выбери: `Europe (eu-west-1)`.
4. Нажми **Add Domain**.
5. Resend покажет тебе 3 или 4 **DNS-записи** (типа TXT и MX). Их нужно добавить в настройках твоего домена.

---

### Шаг 3: Настройка DNS (Где куплен домен)
Открой сайт, где ты покупал домен `cvpilot.uz` (например, Узинфоком, Eskiz, Reg.ru и т.д.) или панель управления хостингом, если DNS делегированы туда (например, панель управления сервером на Ubuntu).

Тебе нужно найти раздел **Настройки DNS** (DNS Records) для домена `cvpilot.uz` и добавить туда записи, которые выдал Resend.

Обычно они выглядят так:

**1. Настройка подписи (DKIM) — ОБЯЗАТЕЛЬНО**
- **Тип (Type):** `TXT`
- **Имя / Хост (Name / Host):** `resend._domainkey`
- **Значение (Value):** `p=MIGfMA0GCSqG...` (длинный код от Resend)

**2. Настройка получателя bounce-отбивок (Return-Path) — ОБЯЗАТЕЛЬНО**
- **Тип (Type):** `MX`
- **Имя / Хост (Name / Host):** `bounce` 
- **Значение (Value):** `feedback-smtp.eu-west-1.amazonses.com` (может отличаться)
- **Приоритет (Priority):** `10`

**3. Настройка политики спама (DMARC) — РЕКОМЕНДУЕТСЯ**
- **Тип (Type):** `TXT`
- **Имя / Хост (Name / Host):** `_dmarc`
- **Значение (Value):** `v=DMARC1; p=none;`

> 💡 **Важно:** В разных панелях регистраторов поле "Имя" (Host) работает по-разному. Если твоя панель сама подставляет `.cvpilot.uz` в конец имени, то пиши просто `resend._domainkey` и `bounce`. Если панель требует полное имя, то пиши `resend._domainkey.cvpilot.uz`.

---

### Шаг 4: Проверка и активация
1. Вернись в панель Resend на страницу Domains.
2. Нажми кнопку **"Verify DNS Records"**.
3. Обновление DNS иногда занимает от 5 минут до пары часов. Если записи добавлены правильно, статус домена изменится на **Verified** (зеленая галочка).
4. Если статус стал Verified, вернись в настройки сервера (файл `.env.prod`) и измени параметр `SMTP_FROM`:
   ```env
   # Было (для песочницы):
   SMTP_FROM=CVPilot <onboarding@resend.dev>
   
   # Стало (для продакшена):
   SMTP_FROM=CVPilot <noreply@cvpilot.uz>
   ```
5. Перезапусти контейнер API:
   ```bash
   docker-compose -f docker-compose.prod.yml up -d api
   ```

Готово! Теперь система будет надежно отправлять 2FA коды на любые адреса электронной почты без попадания в спам.
